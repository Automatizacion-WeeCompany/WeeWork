# AutomatizacionFlexSalud
Repositorio para los flujos de flex salud
# Introduction 
Proyecto que contiene flujos automatizados del proyecto Flex Salud-GMm

# Getting Started
Al momento de descargar el proyecto seguir los siguintes pasos: 
1. Descar e instla Node.js (si ya cuentas con la instalacion global no es necesario hacerlo en cada repositorio).
2. Verificar la version que se tiene instalada con el comando "node -v".
3. Instala globalmente el lenguaje TypeScript con el comando "npm install -g typescript" (si ya lo hiciste anteriormente no es necesario instalar de nuevo)
4. Verificamos que TSC funciona de manera correcta con el comando "tsc -v"
5. Asegurarse de estar en la ruta correspondiente donde se descargo el proyeto en la terminal usualmente se encunetra en "C:\Git"
6. Para inicializar las librerias ejecutar el comando "npx install" en una terminal (solo la primera vez)
7. Instala playwright con el comando "npx playwright install"
8. En caso de agregar librerias que seran utilizadas solo en ambienes de desarrollo, agreagrlas con "npm install <package>" 
9. Indicar si la libreria es requerida para el proyecto
